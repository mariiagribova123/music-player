# Forma player

Адаптивный аудиоплеер, который группирует музыку по настроению. Для запуска нужен Node.js:

```sh
node serve.cjs
```

Откройте `http://localhost:5173`. На телефоне в той же Wi-Fi-сети можно открыть `http://IP-АДРЕС-КОМПЬЮТЕРА:5173`.

## Что умеет

- Добавлять сразу несколько MP3, WAV, M4A, AAC, OGG или FLAC-файлов.
- Определять настроение по названию и характеристикам звучания и раскладывать треки по карточкам Vibe, Party, Chill, Focus, Dream, Drive и Glow.
- Создавать собственную доску настроения кнопкой `+`, выбирать её цвет и сразу добавлять на неё несколько треков.
- Запускать карточку как непрерывную подборку, переключать треки, сохранять любимые настроения и искать по коллекции.
- Менять энергию подборки с помощью «Живой скульптуры».
- Создавать пространство «Одна волна вместе» для компании до восьми человек. Участники выбирают настроение, управляют общей очередью и отправляют реакции.

Добавленные файлы обрабатываются локально и не загружаются на сервер. Поэтому собственная музыка и пользовательские доски живут до обновления страницы. Общие пространства используют встроенную музыкальную подборку и хранятся в памяти сервера до его перезапуска или шести часов без активности.

Интерфейс рассчитан на узкие телефоны от 320 px, обычные телефоны, планшеты, ноутбуки и широкие экраны. Плеер и нижняя навигация остаются доступными во время прокрутки.
